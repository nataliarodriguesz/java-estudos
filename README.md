# Java Estudos

Repositório dedicado aos meus estudos de Java.

Aqui estão reunidos projetos desenvolvidos ao longo da minha jornada de aprendizado na linguagem, desde conceitos básicos até programação orientada a objetos e desenvolvimento de sistemas.

---

# ☕ Tecnologias

- Java
- Programação Orientada a Objetos (POO)

---

# 📚 Organização do repositório

O repositório está dividido em duas principais áreas:

## 📖 java-iniciante

Contém projetos desenvolvidos durante os estudos iniciais da linguagem Java.

### Estrutura

```txt
java-iniciante/
└── 01_ProjetosAula/
```

Nesta etapa foram praticados conceitos como:

- Variáveis
- Estruturas condicionais
- Estruturas de repetição
- Métodos
- Vetores
- Lógica de programação

---

## 💻 java-intermediario

Contém projetos desenvolvidos durante os estudos intermediários da linguagem.

### Estrutura

```txt
java-intermediario/
├── 01_ProjetosAula/
├── 02_ProjetoFinal/
└── 03_SistemaBiblioteca/
```

Nesta etapa foram praticados conceitos como:

- Programação Orientada a Objetos
- Encapsulamento
- Classes e objetos
- Herança
- Polimorfismo
- Organização de sistemas em Java
